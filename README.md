# Famoxe Beauty Lab – React + Tailwind + Framer Motion

```
npm install
npm run dev      # local preview
npm run build    # production build -> dist/
```

Everything lives in `src/App.jsx`. Edit the WhatsApp number, TikTok link, services, gallery and map at the top of that file.
Photos: `public/images/`. Favicons / app icons: `public/icons/`, `public/favicon.*`, `public/site.webmanifest`.
